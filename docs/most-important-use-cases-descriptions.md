# Ewidencjonowanie zwierząt
Pracownik schroniska może dodawać zwierzęta do systemu, edytować dane oraz aktualizować ich statusy. Ma możliwość prowadzenia dokumentacji medycznej, historii szczepień. System zapewnia aktualną ewidencję zwierząt oraz dostęp do informacji o ich stanie zdrowia.

# Przeglądanie katalogu i umawianie wizyt

Odwiedzający może przeglądać publiczny katalog zwierząt dostępnych do adopcji, korzystać z filtrów i poznać wybrane szczegóły dotyczące zwierzęcia. Zarejestrowany adoptujący może umówić wizytę zapoznawczą w dostępnym terminie.

# Obsługa procesu adopcyjnego
Adoptujący może złożyć wniosek i śledzić jego status. Pracownik schroniska rozpatruje wniosek, podejmuje decyzję o jego akceptacji bądź odrzuceniu. Po pozytywnym rozpatrzeniu rejestruje przekazanie zwierzęcia. System zachowuje najważniejsze informacje o procesie adopcyjnym: datę przekazania, dane umowy. Zwierzę otrzymuje status `Adoptowane` i system usuwa je z katalogu zwierząt możliwych do wyświetlenia na stronie i adopcji.
